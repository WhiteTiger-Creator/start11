# ledgerstore 2.1

Released 2024-07-19.

## Merge

- **Version precedence is sequence-only.** Levels no longer participate in
  choosing the surviving version: the record with the globally highest
  sequence number wins regardless of which level it sits in, with the
  lexicographically greatest segment id breaking a tie. The 1.5 level-first
  rule is withdrawn now that 2.0's monotonic sequence allocator makes sequence
  numbers comparable across levels.

## Index

- Shard boundaries are recomputed incrementally rather than from scratch.

## Fixed

- `ledgerctl explain-key` reported the pre-2.0 winner.
