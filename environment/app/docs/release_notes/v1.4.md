# ledgerstore 1.4

Released 2023-04-03.

## Merge

- **Key admissibility.** Keys are validated at merge time rather than at write
  time. A record whose key is empty, longer than 64 bytes when encoded as
  UTF-8, or which carries any character below U+0020 is dropped from the merge
  and never reaches the base. It is not an error and the segment is not
  rejected; only the offending record goes.
- Merge statistics are reported per level instead of per segment.

## Operations

- The background compactor backs off when the write path is saturated.
- New metric `merge.dropped_records`.

## Fixed

- `ledgerctl verify` exited zero on a missing segment file.
