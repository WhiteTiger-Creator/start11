# ledgerstore 1.7

Released 2023-10-02.

## Recovery

- **All-or-nothing admission of unlinked segments.** The 1.3 truncate-to-last-
  valid-record recovery is withdrawn. An unlinked segment left behind by an
  interrupted compaction is admitted only if its trailer is present, its
  record count equals the number of body records actually on disk, and the
  trailer checksum matches the checksum recomputed over those body lines. If
  any of the three fails, the entire segment is discarded and none of its
  records take part in the merge.

  Truncation silently dropped the tail of a flush while leaving its earlier
  records live, which resurrected keys that the lost tail had deleted.

## Operations

- `ledgerctl recover --list` names the segments that would be discarded.

## Fixed

- The recovery path leaked a file descriptor per scanned segment.
