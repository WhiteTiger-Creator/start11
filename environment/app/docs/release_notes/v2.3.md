# ledgerstore 2.3

Released 2024-11-21.

## Recovery

- **Admitted unlinked segments enter at level 1**, not level 0, so that a
  recovery does not widen an already crowded level 0. Sequence numbers are
  still assigned from the checkpoint.

## Index

- **Shard boundaries follow the key count.** With values stored out of line
  since 2.0, a shard's stored bytes no longer predict its read cost, so the
  base is divided into shards holding an equal number of keys.

## Compaction planning

- The plan spans levels 0 and 1 together; a level-1 segment is a candidate on
  the same terms as a level-0 segment.

## Fixed

- `ledgerctl plan --explain` printed scores from the previous run.
