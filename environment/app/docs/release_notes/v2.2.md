# ledgerstore 2.2

Released 2024-09-30.

## Collation

- **Case-insensitive key order.** Ordered structures compare keys after
  folding them to lower case, with the raw bytes breaking a tie, so that
  `Acct:1` and `acct:1` land in the same shard. This replaces the 1.6 raw-byte
  collation.

## Compaction planning

- Sizes are charged in whole mebibytes, rounded **down**, so that a segment
  just over a boundary is not charged for a nearly empty mebibyte.

## Fixed

- The planner could exceed the budget by one mebibyte after rounding.
