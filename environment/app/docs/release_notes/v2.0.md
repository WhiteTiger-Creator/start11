# ledgerstore 2.0

Released 2024-05-08. Requires a manifest migration; not applied to 1.9 nodes.

## Merge

- **Tombstones are retained.** The 1.8 suppression is reverted. A key whose
  winning version is a delete is written to the base as a row carrying
  `"deleted": true` and a stored size of zero, so that the streaming replica
  protocol introduced in this release can observe deletes without shipping
  whole segments.

## Operations

- `ledgerctl migrate` rewrites the manifest into the 2.x layout.
- The 1.x on-disk format is readable but not writable by 2.0.

## Fixed

- A deadlock between the flush thread and the manifest reloader.
