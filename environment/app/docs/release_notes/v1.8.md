# ledgerstore 1.8

Released 2023-11-27.

## Merge

- **Tombstone semantics.** When the winning version of a key is a delete, the
  key is suppressed from the merged base entirely: no row is written for it.
  Earlier releases emitted a row carrying the tombstone so that replicas could
  observe the delete, which is no longer needed now that replication ships the
  segment files themselves.
- A tombstone still counts as a version of the key for version-chain depth.

## Operations

- `merge.suppressed_keys` is reported alongside `merge.dropped_records`.

## Fixed

- Level-2 compaction could hold the manifest lock for the whole merge.
