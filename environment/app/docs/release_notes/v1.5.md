# ledgerstore 1.5

Released 2023-06-20.

## Merge

- **Version precedence.** The surviving version of a key is now chosen by
  level first: the record from the *lowest* level wins, whatever its sequence
  number, because a lower level is by construction the more recently compacted
  view. Within one level the highest sequence number wins, and if two records
  in the same level still tie, the lexicographically greatest segment id wins.

  This replaces the 1.4 behaviour of taking the globally highest sequence
  number, which produced stale reads after a level-1 compaction overtook a
  level-0 flush that had not yet been linked.

## Operations

- `ledgerctl explain-key` shows the full version chain and which record won.

## Fixed

- Manifest reload could observe a partially rewritten level list.
