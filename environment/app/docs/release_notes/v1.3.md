# ledgerstore 1.3

Released 2023-02-14.

## Storage

- Segment files carry a trailer record holding the body record count and a
  truncated SHA-256 over the serialised body lines. Older segments without a
  trailer are still readable and are treated as intact.
- **Torn segment recovery.** A segment whose body disagrees with its trailer is
  truncated at the last record that parses, and the truncated body is merged as
  normal. Operators reported this recovers most of an interrupted flush.
- Compaction now writes into a scratch directory and links the finished segment
  into the manifest as its last action, so an interrupted compaction leaves
  unlinked segments behind rather than a half-written manifest.

## Operations

- `ledgerctl status` prints the checkpoint sequence number.
- The flush thread no longer holds the manifest lock while fsyncing.

## Fixed

- A rare crash when the manifest was reloaded during compaction.
- `ledgerctl compact --dry-run` counted level-1 segments twice.
